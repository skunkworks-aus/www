A FEW USEFUL ANSWERS

Before you enquire.

Does automation always involve AI?

No. Many tasks work best with simple rules and connections. AI can help with tasks such as preparing a draft, where it suits the job.

Can you connect any app?

We need to check the integrations, access and costs supported by your apps. We explain limitations before agreeing the build.

Will messages be sent automatically?

That depends on the workflow we agree. The example above prepares a reply for a person to review; it does not send it automatically.

What is Skunkie?

Skunkie is the name we use for AI assistants within Skunkworks products and workflows. We explain the actual task and controls rather than asking you to buy an unspecified AI promise.

Which task would you like to stop repeating?

Tell us what happens now and which tools you use.
